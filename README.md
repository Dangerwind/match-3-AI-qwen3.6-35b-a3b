# 💎 Match-3

Небольшая браузерная игра в жанре **Match-3 / "Три в ряд"**, написанная на чистом JavaScript, HTML и CSS.

Игрок меняет местами соседние кристаллы. Если после обмена образуется ряд из трёх или более одинаковых кристаллов по горизонтали или вертикали, они исчезают. Кристаллы сверху падают вниз, а освободившиеся клетки заполняются новыми кристаллами.

Игра продолжается ограниченное время, а за уничтоженные кристаллы начисляются очки.

## 🎮 Игровой процесс

1. В начале игры выберите количество типов кристаллов.
2. Игровое поле заполняется случайным образом.
3. Выберите кристалл и соседний с ним кристалл.
4. Кристаллы поменяются местами.
5. Если образовался ряд из 3 или более одинаковых кристаллов, они исчезнут.
6. Кристаллы сверху упадут вниз.
7. Пустые клетки заполнятся новыми кристаллами.
8. Если после падения образуется новая комбинация, она автоматически уничтожается.
9. За уничтоженные кристаллы начисляются очки.
10. После окончания времени игра завершается.

### Пример комбинации

```text
🔴 🔴 🔴
```

Удаляются три кристалла и игрок получает:

```text
+3
```

Для четырёх:

```text
🔵 🔵 🔵 🔵
```

игрок получает:

```text
+4
```

И так далее.

## ⚙️ Настройки игры

Основные параметры игры вынесены в JavaScript-константы.

### Размер игрового поля

```javascript
const BOARD_ROWS = 8;
const BOARD_COLS = 8;
```

Можно изменить размер поля, например:

```javascript
const BOARD_ROWS = 10;
const BOARD_COLS = 10;
```

### Время игры

Продолжительность игры задаётся отдельной константой:

```javascript
const GAME_TIME = 60;
```

Например, чтобы сделать игру на 90 секунд:

```javascript
const GAME_TIME = 90;
```

### Количество типов кристаллов

Минимальное количество типов:

```text
4
```

Игрок может выбрать количество типов кристаллов перед началом игры.

Чем больше типов кристаллов используется, тем сложнее создавать комбинации.

## 🧠 Логика игры

Основной игровой цикл выглядит следующим образом:

```text
Игрок выбирает два соседних кристалла
                ↓
          Обмен кристаллов
                ↓
        Поиск комбинаций
                ↓
       Есть комбинация?
          /          \
        Нет           Да
         ↓             ↓
  Вернуть обратно   Удалить
                       ↓
                  Начислить очки
                       ↓
                 Кристаллы падают
                       ↓
                 Создать новые
                       ↓
              Снова найти комбинации
                       ↓
                Есть новые?
                  /       \
                Да         Нет
                ↓           ↓
             Повтор       Конец хода
```

## 💥 Каскадные комбинации

Одной из особенностей игры являются цепные комбинации.

Например:

```text
Ход игрока
    ↓
3 кристалла уничтожены
    ↓
Кристаллы падают
    ↓
Появились новые кристаллы
    ↓
Образовалась новая комбинация
    ↓
Новая комбинация уничтожается
    ↓
Кристаллы снова падают
```

Такие комбинации происходят автоматически.

## 🏆 Система очков

Количество полученных очков зависит от количества уничтоженных кристаллов.

| Комбинация | Очки |
|------------|------|
| 3 | +3 |
| 4 | +4 |
| 5 | +5 |
| 6 | +6 |
| 7 | +7 |
| ... | ... |

Лучший результат сохраняется в браузере с помощью:

```javascript
localStorage
```

Поэтому рекорд сохраняется даже после закрытия страницы.
